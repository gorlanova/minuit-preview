# Pourquoi Minuit

Minuit a été conçu pour s'adapter à un large éventail de cas d'usage, selon les principes suivants :

## Configuration minimale

L'objectif principal est de fournir des composants prêts à l'emploi avec le moins de configuration possible. 95 % du temps, vous n'avez pas besoin de configurer les éléments internes d'un composant, seulement les données à afficher. Vous gardez ainsi un code propre et concis, et laissez Minuit s'occuper du reste.

## De nombreuses options

Quand vous avez besoin de fonctionnalités plus avancées, Minuit propose un large éventail d'options pour personnaliser l'apparence et le comportement des composants : variantes d'affichage, structures de données complexes, logique additionnelle, etc. Vous choisissez le niveau de complexité qui vous convient, sans être submergé d'options inutiles.

## Styles à faible spécificité

Les composants sont stylés avec du CSS à faible spécificité, ce qui vous permet d'appliquer vos propres styles sans avoir recours à `!important` ni à des sélecteurs complexes. Minuit fournit aussi un système de design global que vous pouvez personnaliser pour changer l'apparence de tous les composants à la fois.

## Accessibilité intégrée

L'accessibilité est un principe fondamental de Minuit. Tous les composants sont conçus pour être accessibles par défaut, en suivant les bonnes pratiques et les critères WCAG. Dans les rares cas où un travail supplémentaire est nécessaire pour garantir une accessibilité complète, Minuit fournit des recommandations claires et des outils pour y parvenir.
